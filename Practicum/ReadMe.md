#Это мой репозиторий Practicum
**Git**
##Основные команды:
'''
###Commit:
  - git add . или git add /_путь_к_ресурсу_
  - git commit -m "комментарий"
  - git push origin master 
'''
###Командная строка:
'''
  - ls 
  - ls -la ~/_path_
  - cd 
'''
###Подключение к репозиторию:
'''
  - ssh -vT - получить расширенную информацию
  - clip <.ssh/key_name.pub
  - ssh -T git@github.com
  - git remote add origin git@github.com:_name/repositoryName.git_
  - git push -u origin master
'''
